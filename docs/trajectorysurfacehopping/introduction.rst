****************************
Introduction to the Tutorial
****************************

In this tutorial, we will study the photophysical dynamics of the methaniminium cation. This molecule serves as a simple model for more complex systems, such as retinal, which plays a key role in biological photophysics. Because methaniminium is often used as a benchmark system in TSH studies, it provides a useful reference to evaluate the results obtained with TD-DFTB and to compare them with both experimental data and higher-level electronic structure methods.

The protocol followed throughout this tutorial is based on a previously published work (`TSH-DFTB+ <https://pubs.acs.org/doi/full/10.1021/acs.jctc.4c01263>`_), where it was applied to this and other systems.
